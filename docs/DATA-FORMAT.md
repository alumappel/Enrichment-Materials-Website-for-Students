# מבנה קובץ התכנים

הקובץ `data/content.json` הוא מקור יחיד לקורסים, לחומרים ולמונחים המקבילים. יש לשמור אותו ב־UTF-8 וב־JSON תקין: בלי הערות ובלי פסיק אחרי השדה האחרון. אין צורך להוסיף קוד HTML לטקסטים.

## המבנה הראשי

| שדה | משמעות |
| --- | --- |
| `schemaVersion` | המספר 1 |
| `revision` | מזהה פרסום ייחודי, עד 150 תווים; משתנה בכל עדכון |
| `updatedAt` | זמן עדכון הקובץ, ISO 8601 עם אזור זמן |
| `courses` | מערך קורסים |
| `synonymGroups` | מערך קבוצות מונחים; יכול להיות ריק |
| `items` | מערך חומרים; יכול להיות ריק |

דוגמה לתאריך: `2026-10-05T09:00:00Z`. העורך מציג ומקבל תאריך לפי שעון ישראל, ללא תלות באזור הזמן של המחשב.

## קורסים

כל קורס כולל `id` קבוע באנגלית ו־`name` בעברית או באנגלית, עד 120 תווים. המזהה יכיל אותיות קטנות, ספרות ומקפים בלבד. אין שמות או מזהים כפולים. קורס ללא חומרים עדיין חוקי.

מזהי תשעת הקורסים: `unity`, `web-development`, `web-design`, `learning-technologies`, `accessibility`, `design`, `learning-skills`, `other`, `computer-science`. שינוי שם לא ישנה מזהה. אין מחיקת קורס דרך העורך. הקורס `other` נשמר גם ללא פריטים.

## פריטי תוכן

| שדה | דרישה |
| --- | --- |
| `id` | מזהה ייחודי וקבוע, עד 150 תווים |
| `addedAt` | תאריך ההוספה, עם אזור זמן; קובע את המיון |
| `updatedAt` | תאריך עדכון התוכן, עם אזור זמן |
| `title` | טקסט חובה עד 100 תווים |
| `description` | טקסט חובה עד 350 תווים |
| `type` | אחד משבעת הערכים שבטבלה להלן |
| `url` | כתובת מלאה ב־http או https, ללא שם משתמש וסיסמה; או קישור לקובץ באתר תחת `/resources/` |
| `courseIds` | מערך לא ריק של מזהי קורסים קיימים, בלי כפילויות |
| `keywords` | מערך טקסטים לחיפוש, עד 100 תווים למונח; יכול להיות ריק |
| `status` | `published` או `archived` |

| סוג | ערך |
| --- | --- |
| אתר | `website` |
| סרטון | `video` |
| כתבה | `article` |
| קורס דיגיטלי | `course` |
| משחק | `game` |
| כלי | `tool` |
| קובץ | `file` |

פריט המשויך לכמה קורסים נשמר פעם אחת, עם כמה ערכים ב־`courseIds`. אין ליצור עותק לכל קורס. עריכה ושחזור אינם משנים את `addedAt`, אלא אם מתקנים אותו במפורש. תאריך ההוספה מוסתר לסטודנטים. אין סטטוס טיוטה.

קישור פנימי לדוגמה: `/resources/scenes-001.pptx`. אפשר גם `resources/scenes-001.pptx`; שתי הצורות נפתחות ביחס לשורש האתר, כולל תיקיית המאגר ב־GitHub Pages. רק תיקיית `resources` מותרת לקישורים פנימיים. אין לקבל ניווט `..`, כתובת המתחילה ב־`//` או נתיב מקומי של Windows. הקובץ עצמו צריך להיות בתיקייה הזו ולהיכלל בהעלאה ל־GitHub. עוגן בקישור חיצוני, כמו `#containers`, נשמר ומובחן מעוגנים אחרים.

ביבוא הנוכחי תאריכי 120 הפריטים המקוריים נשמרו בדיוק כ־`2026-10-05T00:00:00Z`, כפי שנמסרו בהמרה. לפריט `item-0121` נשמר זמן ההוספה `2026-10-05T14:51:59Z`. אין לשנות תאריכי מקור בזמן החלפת הנתונים; תצוגת הזמן בעורך ממשיכה להיות לפי שעון ישראל.

## מונחים מקבילים

כל קבוצה כוללת `id` ייחודי ו־`terms`: לפחות שני מונחים שונים, עד 100 תווים למונח. לדוגמה:

```json
{ "id": "unity-terms", "terms": ["Unity", "יוניטי"] }
```

כשמוגדר מילון, החיפוש פועל בשני הכיוונים ומזהה ביטויים מרובי מילים לפני פיצול השאילתה. הוא מתעלם מניקוד, מפיסוק, מרווחים עודפים ומגודל אותיות באנגלית. כל מילה או ביטוי בשאילתה צריכים להתאים לאחד משדות הפריט. הוא אינו מתרגם אוטומטית מונחים שלא הוגדרו במילון. ביבוא הנוכחי המילון ומילות המפתח ריקים, בהתאם לטבלת המקור.

## לפני החלפה

הריצו `node scripts/validate-data.mjs PATH` כדי לבדוק קובץ חלופי בלי לשנות את המערכת. לאחר החלפת `data/content.json`, הריצו `node scripts/revise-data.mjs` לקבלת מזהה גרסה חדש. העלו את הקובץ המעודכן לענף הפרסום. פתיחה מחדש או רענון לאחר פריסה ימשכו את התכנים החדשים.
